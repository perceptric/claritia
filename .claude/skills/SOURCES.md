# Skill packs

Third-party Claude Code skills, copied as-is from their public repos. Each folder here is one skill.

| Pack | Source |
| --- | --- |
| Taste Skills | github.com/Leonxlnx/taste-skill |
| Agent Skills | github.com/addyosmani/agent-skills (its `test-driven-development` is renamed `addy-test-driven-development`) |
| Caveman | github.com/JuliusBrussee/caveman |
| Graphify | github.com/Graphify-Labs/graphify (needs the CLI: `uv tool install graphifyy`) |
| UI UX Pro Max | github.com/nextlevelbuilder/ui-ux-pro-max-skill |
| Ponytail | github.com/DietrichGebert/ponytail |
| Anthropic Skills | github.com/anthropics/skills |
| Matt Pocock Skills | github.com/mattpocock/skills |
| Superpowers | github.com/obra/superpowers |
| Karpathy Skills | github.com/forrestchang/andrej-karpathy-skills |

Running cost: none on its own. Skills only add to Claude tokens when one loads in a session.
